# 调试参数

App 支持通过 Intent extra 切换页面/状态，方便无 adb 点击权限时做截图回归（MIUI 等机型 adb 模拟点击会被系统拒绝）。

```powershell
adb shell am start -n com.phonekb/.MainActivity --ei tab 2 --ei orient 2
```

同一次启动可叠加多个参数，参数处理完会启动页面并记录到 SharedPreferences（部分参数会改变当前状态）。

| 参数 | 取值 | 说明 |
|---|---|---|
| `--ei tab N` | 0..5 | 切换页面：0 键盘 / 1 触控板 / 2 媒体 / 3 手柄 / 4 双手 / 5 单手 |
| `--ei orient N` | 0/1/2 | 0 跟随系统 / 1 强制横屏 / 2 强制竖屏 |
| `--ei rotate 1` | 1 | 切换一次横竖屏（等价于点「旋转」键） |
| `--ei kblayout N` | 0/1 | 键盘布局：0 电脑布局 / 1 手机布局 |
| `--ei kbpage N` | 0/1 | 键盘页：0 字母页 / 1 符号页 |
| `--ei kbsplit N` | 30..62 | 竖屏键盘页触控区占比（%） |
| `--ei touchsplit N` | 45..100 | 竖屏触控板页功能区占比（%） |
| `--ei mediasplit N` | 55..100 | 竖屏媒体页功能区占比（%） |
| `--ei overlay N` | 1/2/3 | 打开浮层：1 数字键盘 / 2 键盘 / 3 触控板 |
| `--ei onehand 1` | 1 | 进入单手模式 |
| `--ei thumb N` | 0/1 | 单手模式：0 遥控台 / 1 拇指键盘 |
| `--ei hand N` | 1/2 | 单手模式：1 右手 / 2 左手 |
| `--ei twoswap N` | 0/1 | 双手模式是否互换触控区/按键板 |

## 截图

```powershell
adb shell screencap -p /sdcard/x.png
adb pull /sdcard/x.png .\x.png
```

## HID 日志

```powershell
adb logcat -d -s PhoneKB-HID:I AndroidRuntime:E
```

关键行：`registerApp ok=...`、`appStatus registered=...`、`state=3 | 已连接 | 设备名`。
