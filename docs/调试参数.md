# 调试参数

App 支持通过 Intent extra 切换页面/状态，方便无 adb 点击权限时做截图回归（MIUI 等机型 adb 模拟点击会被系统拒绝）。

```powershell
adb shell am start -n com.phonekb/.MainActivity --ei tab 2 --ei orient 2
```

同一次启动可叠加多个参数，参数处理完会启动页面并记录到 SharedPreferences（部分参数会改变当前状态）。

| 参数 | 取值 | 说明 |
|---|---|---|
| `--ei tab N` | 0..5 | 切换页面：0 键盘 / 1 触控板 / 2 媒体 / 3 手柄 / 4 双手 / 5 单手 |
| `--ei orient N` | 0/1/2 | 0 跟随系统 / 1 强制横屏 / 2 强制竖屏 |
| `--ei rotate 1` | 1 | 切换一次横竖屏（等价于点「旋转」键） |
| `--ei kblayout N` | 0/1 | 键盘布局：0 电脑布局 / 1 手机布局 |
| `--ei kbpage N` | 0/1 | 键盘页：0 字母页 / 1 符号页 |
| `--ei kbsplit N` | 30..62 | 竖屏键盘页触控区占比（%） |
| `--ei touchsplit N` | 45..100 | 竖屏触控板页功能区占比（%） |
| `--ei mediasplit N` | 55..100 | 竖屏媒体页功能区占比（%） |
| `--ei overlay N` | 1/2/3 | 打开浮层：1 数字键盘 / 2 键盘 / 3 触控板 |
| `--ei onehand 1` | 1 | 进入单手模式 |
| `--ei thumb N` | 0/1 | 单手模式：0 遥控台 / 1 拇指键盘 |
| `--ei hand N` | 1/2 | 单手模式：1 右手 / 2 左手 |
| `--ei twoswap N` | 0/1 | 双手模式是否互换触控区/按键板 |
| `--ei simw N` | 240..600 | 模拟屏幕宽度（dp），用来在没有窄屏手机时验证自适应布局；0 关闭模拟 |
| `--ef simfont F` | 0.85..1.3 | 模拟系统字体缩放倍数（配合 simw 验证大字体） |
| `--ei uisize N` | 0..3 | 界面大小：0 自动 / 1 小 / 2 标准 / 3 大（写入设置并重新创建界面） |
| `--ei uisizedlg 1` | 1 | 直接打开「界面大小」对话框 |
| `--ei moremenu 1` | 1 | 直接展开顶部「更多」菜单（用于截图/验证折叠项，等效于点「更多」） |
| `--ei gptest N` | 1..5 | 手柄自检：1 按键 / 2 方向 / 3 全部 / 4 对角 / 5 原始 hat 扫描（配合主机 `getevent` 验证映射） |
| `--ei gptype N` | 0/1 | 手柄移动盘类型：0 按键 / 1 圆盘（写入设置） |
| `--ei gppad N` | 60..150 | 手柄**移动盘**大小百分比（默认 100，写入设置） |
| `--ei gpbtn N` | 60..150 | 手柄**按键**大小百分比（ABXY / 肩键 / 菜单键，默认 100，写入设置） |
| `--ei gpsize N` | 60..150 | 一次设置两个滑块（移动盘 + 按键） |
| `--ei gpdialog 1` | 1 | 直接打开「手柄设置」弹窗（用于截图） |
| `--ei brighttest 1` | 1 | 连续发蓝牙亮度键码（Consumer 0x006F / 0x0070），配合平板 `getevent` 验证是否被系统接收 |
| `--ei brightwifi N` | 整数，正=调亮 / 负=调暗 | 直接触发 N 次 WiFi 伴侣调亮度（adb 无法点手机屏幕时验证整条链路） |

## 截图

```powershell
adb shell screencap -p /sdcard/x.png
adb pull /sdcard/x.png .\x.png
```

## HID 日志

```powershell
adb logcat -d -s PhoneKB-HID:I AndroidRuntime:E
```

关键行：`registerApp ok=...`、`appStatus registered=...`、`state=3 | 已连接 | 设备名`。
## WiFi 伴侣调试

手机端（先 `--ei companion 1` 打开发送页，其余 extra 会一起转发过去）：

```powershell
adb shell am start -n com.phonekb/.MainActivity --ei companion 1
adb shell am start -n com.phonekb/.MainActivity --ei companion 1 --es pairhost 127.0.0.1 --ei pairport 47654 --es pairtoken 123456   # 跳过扫码，直接按已知信息配对
adb shell am start -n com.phonekb/.MainActivity --ei companion 1 --es ctoken 123456                                            # 设置配对码并启动监听
adb shell am start -n com.phonekb/.MainActivity --ei companion 1 --es ctest true --es ctext "测试文字"                          # 测试发送文本
adb shell am start -n com.phonekb/.MainActivity --ei companion 1 --es cclip true --es ctext "剪贴板内容"                        # 测试发送剪贴板
adb shell am start -n com.phonekb/.MainActivity --ei companion 1 --ei cscan 1                                               # 打开扫码相机
```

注意：`pairjson` 这种带 JSON 的参数经 PowerShell → adb → 设备 sh 会被破坏，测试请用 `pairhost/pairport/pairtoken`。`CompanionActivity` 是 exported=false，不能直接 `am start`，必须由 MainActivity 转发。

平板端（伴侣 App）：

```powershell
adb shell am start -n com.phonekb.companion/.MainActivity --es pairtoken 123456                       # 固定配对码并刷新二维码/启动监听
adb shell am start -n com.phonekb.companion/.MainActivity --es host 10.0.0.2 --es token 123456 --ei connect 1 --ei focus 1   # 手动连接指定手机
```

平板通常没有 adb，实际排查看手机端「接收 / 日志」面板即可。
