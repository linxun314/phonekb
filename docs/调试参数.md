# 调试参数

App 支持通过 Intent extra 切换页面/状态，方便无 adb 点击权限时做截图回归（MIUI 等机型 adb 模拟点击会被系统拒绝）。

```powershell
adb shell am start -n com.phonekb/.MainActivity --ei tab 2 --ei orient 2
```

同一次启动可叠加多个参数，参数处理完会启动页面并记录到 SharedPreferences（部分参数会改变当前状态）。

| 参数 | 取值 | 说明 |
|---|---|---|
| `--ei tab N` | 0..4 | 切换页面：0 键盘 / 1 触控板 / 2 媒体 / 3 手柄 / 4 双手 |
| `--ei orient N` | 0/1/2 | 0 跟随系统 / 1 强制横屏 / 2 强制竖屏 |
| `--ei rotate 1` | 1 | 切换一次横竖屏（等价于点「旋转」键） |
| `--ei mousegap N` | 2–12 | 指针上报节奏（ms），等价于「更多设置 → 指针上报节奏」，会写入设置 |
| `--ei mousetest N` | ms | 鼠标压力测试：240 Hz 左右来回移动 N 毫秒（<1000 视为 4000），配合 `--ei hidlog 1` 看 `mouse ctx=…ms dx=…` 节奏 |
| `--ei devmode N` | 0/1 | 设备模式：0 平板模式（Android）/ 1 电脑模式（Windows），等价于点顶栏「平板 / 电脑」，会写入设置 |
| `--ei modemenu 1` | 1 | 打开顶栏「平板 / 电脑」折叠菜单（等价于点那个带 ⌄ 的按钮），截图用 |
| `--ei devlist 1` | 1 | 打开「连接设备」面板（等价于点顶栏「设备」），截图用；注意它走主线程 Handler 延迟 1.6 s，配合 `--ei orient` 时不会被旋转重建吃掉 |
| `--ei devcut N` | 毫秒 | N 毫秒后执行一次「断开」，与点设备列表里的「断开」是同一条代码路径（`HidManager.disconnectCurrent()`）；用来验证断开后不会被自动重连拉回去 |
| `--ei kblayout N` | 0/1 | 键盘布局：0 电脑布局 / 1 手机布局 |
| `--ei kbpage N` | 0/1 | 键盘页：0 字母页 / 1 符号页 |
| `--ei kbsplit N` | 30..62 | 竖屏键盘页触控区占比（%） |
| `--ei touchsplit N` | 45..100 | 竖屏触控板页功能区占比（%） |
| `--ei mediasplit N` | 55..100 | 竖屏媒体页功能区占比（%） |
| `--ei overlay N` | 1/2/3 | 打开浮层：1 数字键盘 / 2 键盘 / 3 触控板 |
| `--ei twoswap N` | 0/1 | 双手模式是否互换触控区/按键板 |
| `--ei simw N` | 240..600 | 模拟屏幕宽度（dp），用来在没有窄屏手机时验证自适应布局；0 关闭模拟 |
| `--ef simfont F` | 0.85..1.3 | 模拟系统字体缩放倍数（配合 simw 验证大字体） |
| `--ei uisize N` | 0..3 | 界面大小：0 自动 / 1 小 / 2 标准 / 3 大（写入设置并重新创建界面） |
| `--ei uisizedlg 1` | 1 | 直接打开「界面大小」对话框 |
| `--ei moremenu 1` | 1 | 直接展开顶部「更多」菜单（用于截图/验证折叠项，等效于点「更多」） |
| `--ei gptest N` | 1..8 | 手柄自检：1 按键 / 2 方向 / 3 全部 / 4 对角 / 5 原始 hat 扫描 / 6 连打 30 次（120ms 间隔）/ 7 快连打 10 次（55ms 间隔）/ 8 摇杆洪泛后按 A（测队列延迟）；配合主机 `getevent` 验证 |
| `--ei hidlog 1` | 0/1 | 打印每条 HID 报告的提交/发出时间（tag `PhoneKB-HID`），用于和主机 `getevent` 对齐算延迟 |
| `--ei hidlegacy 1` | 0/1 | 临时切回旧版「即发即忘」发送器，用于 A/B 对比；默认关闭 |
| `--ei gptype N` | 0/1/2 | 手柄移动盘类型：0 按键 / 1 圆盘 / 2 摇杆（写入设置） |
| `--ei gpstickhat N` | 0/1 | 摇杆同时发方向键（推杆时同时发 hat，兼容只认方向键的主机） |
| `--ei gppad N` | 60..200 | 手柄**移动盘**大小百分比（默认 100，写入设置）；实际会按屏幕空间钳制，弹窗里显示真实值 |
| `--ei gpbtn N` | 60..200 | 手柄**按键**大小百分比（ABXY / 肩键 / 菜单键，默认 100，写入设置） |
| `--ei gpsize N` | 60..200 | 一次设置两个滑块（移动盘 + 按键） |
| `--ei gpb 0\|1` | 0/1 | 大键模式：隐藏肩键 / 摇杆 / 菜单键，只留方向盘与 ABXY（竖屏上下竖排），写入设置 |
| `--ei gprz 0\|1` | 0/1 | 右摇杆轴向：0 = RX/RY（默认）/ 1 = Z/RZ（需要平板重新配对） |
| `--ei gpdialog 1` | 1 | 直接打开「手柄设置」弹窗（用于截图） |
| `--ei gpsim N` | 1..4 | 模拟手指打一遍 UI（绕过 MIUI 禁止 `adb input`）：1 点 A / 2 右摇杆向右拖 / 3 左摇杆 / 4 所有非方向键各点一次；用于验证命中区与摇杆链路 |
| `--ei gpreset 1` | 1 | 清掉全部自定义布局偏移（横竖屏 × 浮键/皮肤四套），修「按键被旧偏移推到屏幕外」 |
| `--ei gplog 1` | 1 | 打印皮肤布局与按键矩形（tag `PhoneKB-GP`），排查遮挡/越界 |
| `--ei gptp N` | 0/1 | 手柄页触控板浮层：1 打开 / 0 关闭（方便截图） |
| `--ei gptpoff N` | 整数 dp | 手柄页触控板浮层的水平偏移（正数 = 往左挪），模拟拖动把手后的位置 |
| `--ei gplayout N` | 0/1 | 手柄布局：0 浮键 / 1 皮肤（自定义在皮肤基础上拖位置） |
| `--ei gpedit 1` | 1 | 进入手柄「编辑布局」模式（蓝色虚线框） |
| `--ei gpfast 0\|1` | 0/1 | 极速模式：关震动 + 摇杆拖动不重绘 + 摇杆上报放宽到 20ms |
| `--ei gphaptic 0\|1` | 0/1 | 手柄震动反馈开关 |
| `--ei sens N` | 40..250 | 指针灵敏度（除以 100），写入设置；160 = 1.6x |
| `--ei rows N` | 1..6 | 滚轮速度（一次滚几行），写入设置 |
| `--ei accel N` | 0/1 | 加速度开关，写入设置 |
| `--ei sensdialog 1` | 1 | 直接打开「指针灵敏度」弹窗（用于截图/验证） |
| `--ei gpcompat 0|1` | 0/1 | 方向键方向修正：1 = 旧配对描述符兼容（逆运算一格），会写入设置 |
| `--ei gptouch N` | 0/1/2 | 手柄页触控板：0 关 / 1 中间面板（默认）/ 2 整片空白（写入设置） |
| `--ei gptouchx 0|1` | 0/1 | 触控点击：0 完整（移动+点击）/ 1 只移动（写入设置） |
| `--ei gpbuzz 1` | 1 | 连振 3 次（60ms），用于验证手机振动是否生效 |
| `--ei brighttest 1` | 1 | 连续发蓝牙亮度键码（Consumer 0x006F / 0x0070），配合平板 `getevent` 验证是否被系统接收 |
| `--ei moredlg 1` | 1 | 直接打开「更多设置」弹窗（点击方式 / 长按阈值 / 极速模式 / 手柄 LT/RT 兼容 / 界面大小 / 指针延迟测量） |
| `--ei seek 2` | 1\|2 | 媒体 −10s / ＋10s 改发标准 Rewind / Fast-Forward（默认 1 = ← / → 方向键），用于在播放器里对照哪种真能 seek |
| `--ei ptrlat 1` | 1 | 打开「指针延迟」弹窗，读最近 128 次移动的 p50/p95（同时写 logcat 的 `PhoneKB-Latency`） |
| `--ei mediatest 1` | 1 | 依次发媒体卡三键：上一段 / 播放暂停 / 下一段（间隔 0.5 s），平板 event11 应看到 KEY_PREVIOUSSONG → KEY_PLAYPAUSE → KEY_NEXTSONG |
| `--ei mediatest 2` | 2 | 发 截屏（PrintScreen / KEY_SYSRQ）后接 多任务（Alt+Tab）：0.8 s 发 SysRq，2.0 s 发 Alt+Tab，平板 event12 应看到 KEY_SYSRQ 与 LEFTMETA+TAB |
| `--ei mediatest 3` | 3 | 连续发亮度 −/＋（Consumer 0x0070 / 0x006F） |
| `--ez wake true` | true | 屏幕休眠时把 Activity 设为 `setTurnScreenOn` + `setShowWhenLocked`，让 `adb screencap` 能拍到画面（否则拍到全黑） |

## 验证媒体键是否到达平板

`getevent` 一次只能抓一个设备，所以分两次抓（「林 Consumer Control」= event11、「林 Keyboard」= event12）：

```powershell
adb -s <平板IP:5555> shell "timeout 10 getevent -lt /dev/input/event11"
adb -s e97880b3 shell am start -n com.phonekb/.MainActivity --ei mediatest 1
```

预期（mediatest 1）：`KEY_PREVIOUSSONG`(0x00B6) → `KEY_PLAYPAUSE`(0x00CD) → `KEY_NEXTSONG`(0x00B5)。

再抓键盘设备（event12）验证 mediatest 2：`KEY_SYSRQ`(0x46) 与 `KEY_LEFTALT`(0xE2) + `KEY_TAB`(0x2B)。

## HID 日志

```powershell
adb logcat -d -s PhoneKB-HID:I AndroidRuntime:E
```

关键行：`registerApp ok=...`、`appStatus registered=...`、`state=3 | 已连接 | 设备名`。
