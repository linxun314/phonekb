# 开源发布指南（GitHub）

仓库：https://github.com/linxun314/phonekb · 默认分支 `main` · 许可证 Apache-2.0

**当前线上版本：v0.25.0（手机端 0.25.0 / 伴侣 0.4.0）**
Release：https://github.com/linxun314/phonekb/releases/tag/v0.25.0

以下命令都在仓库根目录 `C:\Users\22453\Desktop\phoneKB` 执行。

## 1. 规则

- **只有用户明确说「上传」时才 push / 打 tag / 发 Release**，不要在改完代码后自动发布
- 仓库与文档只介绍**当前版本**：README、CHANGELOG、docs/ 都不保留历史版本说明
- 发布后如果有人问旧版本，直接给最新 Release 链接即可

## 2. 构建两个 APK

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Clean -Module app -VersionName 0.25.0 -VersionCode 39
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Clean -Module companion -VersionName 0.4.0 -VersionCode 4
```

产物：`build\PhoneKB.apk`（手机）、`build\PhoneKB-Companion.apk`（平板伴侣）。
也可以上 GitHub Actions 的 Artifacts 取自动构建的 debug APK。

## 3. 提交与推送

```powershell
git add -A
git commit -m "v0.25.0: 指针灵敏度 + 手柄三布局/摇杆/自定义编辑"
git push origin main
git tag v0.25.0
git push --tags
```

## 4. 发布 GitHub Release

1. 仓库 → Releases → **Create a new release**
2. Tag 选 `v0.25.0`，Target 选 `main`
3. 标题：`v0.25.0 — 指针灵敏度 + 手柄三布局`
4. 描述直接从 [CHANGELOG.md](../CHANGELOG.md) 复制（只写当前版本）
5. 上传两个 Assets（重命名后上传）：
   - `build\PhoneKB.apk` → `PhoneKB-0.25.0.apk`
   - `build\PhoneKB-Companion.apk` → `PhoneKB-Companion-0.4.0.apk`
6. **Publish release**

> 老版本的 Release 不必保留；如果确实要清理，删除旧 Release 后记得把对应的旧 tag 一起删掉。

## 5. 版本号要改的地方

| 位置 | 说明 |
|---|---|
| `app/src/main/AndroidManifest.xml` | `android:versionCode` / `android:versionName` |
| `app/build.gradle` | `versionCode` / `versionName` |
| `tools/build.ps1` | `$VersionName` / `$VersionCode` 默认值 |
| `MainActivity` 的 footer | `PhoneKB vX.Y.Z · ...` |
| `companion/src/main/AndroidManifest.xml`、`companion/build.gradle` | 伴侣版本号 |

## 6. 关于签名

- 当前 APK 用仓库 `keys/debug.keystore`（debug 签名，已 gitignore）签名，可正常安装，适合自用/测试分发
- 想让 APK 长期可升级（同 keystore 才能覆盖安装），**务必备份 `keys/debug.keystore`**
- 要上应用商店或长期正式分发，建议生成 release keystore：

```powershell
keytool -genkeypair -v -keystore keys\release.keystore -alias phonekb -keyalg RSA -keysize 2048 -validity 10000
```

然后改 `tools/build.ps1` 的 keystore/alias 参数，先用 `apksigner verify -v` 验证再发布。

## 7. 不要提交的东西

- `keys/`、`local.properties`、`_local/`（本地素材、反编译参考代码，含 GPL/AGPL，不能进仓库）
- 根目录大量临时截图 / 效果图（只把要展示的放进 `docs/screenshots/`）
- `.gitignore` 已排除以上内容
