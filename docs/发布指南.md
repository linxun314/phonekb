## 3. 构建可发布的 APK

任选一种：

```powershell
# 方式一：项目自带脚本（不装 Android Studio），会同时产出两个 APK
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Clean -Module app       -VersionName 0.15.0 -VersionCode 20   # build\PhoneKB.apk
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Clean -Module companion -PackageName com.phonekb.companion -OutName PhoneKB-Companion -VersionName 0.3.0 -VersionCode 3   # build\PhoneKB-Companion.apk

# 方式二：Gradle（一次构建两个模块）
.\gradlew assembleDebug
# 产物：app\build\outputs\apk\debug\app-debug.apk
#       companion\build\outputs\apk\debug\app-debug.apk
```

验证 APK（可选）：

```powershell
adb install -r build\PhoneKB.apk
```

## 4. 发布 GitHub Release

1. 仓库页 → 右侧 **Releases** → **Create a new release**；
2. Tag 填 `v0.15.0`，Target 选 main，Release title 例如 `v0.15.0 — WiFi 伴侣通道`；
3. 描述可以从 [CHANGELOG.md](../CHANGELOG.md) 复制；
4. 上传两个 Assets（重命名后上传）：
   - `build\PhoneKB.apk` → `PhoneKB-0.15.0.apk`
   - `build\PhoneKB-Companion.apk` → `PhoneKB-Companion-0.3.0.apk`
5. 点击 **Publish release**。

这样别人就能在 Releases 页直接下载安装（手机装 PhoneKB，平板装伴侣）。

## 5. 以后更新版本的流程

1. 修改代码；
2. 改版本号（每个模块三处保持一致）：
   - 手机：`app/src/main/AndroidManifest.xml`、`app/build.gradle`、`tools/build.ps1` 默认参数；
   - 伴侣：`companion/src/main/AndroidManifest.xml`、`companion/build.gradle`；
3. 更新 `CHANGELOG.md` 和 `docs/`（使用说明 / 需求与进展 / 验证记录）；
4. 构建 + 真机验证；
5. 提交并打 tag：`git add -A && git commit -m "vX.Y.Z: 说明" && git push && git tag vX.Y.Z && git push --tags`；
6. 按第 4 步建新的 Release。

## 6. 关于签名

- 当前 APK 使用仓库 `keys/debug.keystore`（debug 签名，已 gitignore，不会进仓库）签名，可以正常安装到手机，适合自用/测试分发。
- 如果你希望这个 APK 长期可升级（同一个 keystore 才能覆盖安装），**请备份好 `keys/debug.keystore`**，不要弄丢。
- 如果要上应用商店或长期正式分发，建议生成 release keystore：

```powershell
keytool -genkeypair -v -keystore keys\release.keystore -alias phonekb -keyalg RSA -keysize 2048 -validity 10000
```

  然后修改 `tools/build.ps1` 里的 keystore/alias 参数为 release 文件，构建后先用 `apksigner verify -v` 验证再发布。

## 7. 注意

- 不要提交 `keys/`、`local.properties`、`_local/`（里面是参考 APK 反编译材料，含 GPL/AGPL 代码，不能进仓库）；`.gitignore` 已排除。
- `_local/` 里还放了历史截图、效果图脚本、本地 Gradle 发行版，都是本地辅助文件，不进仓库。
- 如果以后换电脑，需要在新机器重新登录 GitHub（或配置 Personal Access Token）才能 push。
