# 使用说明

> PhoneKB 让 Android 手机变成蓝牙键盘 / 触控板 / 媒体遥控器 / 手柄。被控设备（平板、电脑）零安装、无需 root。

## 1. 环境要求

| 端 | 要求 |
|---|---|
| 手机（控制端） | Android 9（API 28）及以上；系统保留 Bluetooth HID Device profile（部分厂商 ROM 会屏蔽） |
| 被控端 | 支持蓝牙键盘/鼠标的设备：Android 平板/手机、Windows、macOS、Linux、iPadOS |

实测环境：Redmi K40（M2012K11AC，Android 13，HyperOS V816.0.10.0.TKHCNXM）→ iQOO Pad2（iPA2453，Android 14，DPD2345E_A_16.2.11.1.W10.V000L1）。

## 2. 安装

1. 下载 `PhoneKB-x.y.z.apk` 并安装；Android 13+ 会询问是否允许安装，需要允许此来源。
2. 首次打开：如提示通知权限，请允许（前台服务保活需要，否则 App 被系统回收后蓝牙会断开）。
3. 蓝牙权限在首次使用时授权。

## 3. 配对（关键步骤）

1. 打开 PhoneKB，App 会自动注册 HID。顶部状态应为「等待配对」或「已连接」。
2. 点右上角 **配对**，按弹窗提示操作：打开手机蓝牙、让手机处于可被发现状态；如果之前配对过，先在手机蓝牙设置里删除旧配对。
3. 在被控设备（平板/电脑）打开蓝牙设置 → 搜索设备 → 找到**手机蓝牙名称**（例如「林」）→ 配对。
4. 回到 App，顶部显示 **已连接 · 设备名** 后即可输入。

> 第一次配对后，如果被控端显示「已连接」但按键无反应，通常在手机蓝牙设置里「取消配对/忘记设备」，再从 App 配对引导重新走一遍即可（HID 需要正确的配对流程）。

### 各平台注意点

- **Android 平板**：配对成功后系统会把它识别为键盘/鼠标，部分平板需在「设置 → 语言和输入法 → 物理键盘」中确认键盘布局。
- **Windows / macOS / Linux**：直接当作标准蓝牙键鼠即可；macOS 可能要求确认键盘类型。
- **iPadOS**：系统只当标准蓝牙键鼠使用，可用字母/数字/快捷键，中文输入依靠 iPad 自带输入法。

## 4. 各页面说明

### 键盘
- 竖屏：上方触控区（可拖动比例），下方键盘；顶部工具区「切换布局」「触控板」。
- 两套布局：**手机布局**（数字行 + 精简字母 + 符号页）、**电脑布局**（Ctrl+C/V/X/A、Alt+Tab、Tab、反斜杠、Ctrl/Alt/Win、方向键）。
- 符号页：`!@#$` 等符号，左下方 ABC 返回字母页。
- 快捷键行与按键会根据横竖屏自动放大/缩小，横屏按键更大。

### 触控板
- 单指移动 → 鼠标移动；单指点击 → 左键；双指点击 → 右键；三指点击 → 中键。
- 双指上下滑 → 滚轮滚动；右侧 ↑ / ↓ 长按可连续滚动。
- 底部左/中/右三个按键支持按住拖动（拖拽文件、选中等场景）。
- 左侧竖条：**数字**（数字键盘浮层）、**键盘**（键盘浮层）、**菜单**；左上角电源键。
- 浮层数字键盘适合输入锁屏密码等纯数字场景。

### 媒体
- 媒体条：上一首 / 播放暂停 / 下一首。
- 两行大圆键：音量 + / 音量 − / 静音 / CC（字幕）；返回 / 主页 / 菜单 / 电源。
- 顶部整行「触控板」按钮：一键弹出触控板浮层（不用切换页面）。
- 功能区高度可拖动调节，留给拇指更舒服的位置。

### 手柄
- 左侧十字键，右侧 X/Y/A/B，L1/R1，底部 SELECT/START；按住可持续发送。

### 双手
- 触控区 + 按键板（音量/媒体/导航/数字+键盘）分工，适合横屏双手握持。
- 顶部「**互换**」键：横屏左右对调 / 竖屏上下对调，状态会记住。

### 单手
- **遥控台**：右侧面板 = 触控区 + 返回/确定/键盘 + 媒体 + 音量，左侧留空方便握持。
- **拇指键盘**：键盘贴着屏幕右侧（可切左手），左侧为「切到遥控台」「切换左右手」。
- 单手模式解决「一只手够不到」的问题，不改变输入字符集（中文仍需被控端输入法）。

## 5. 横竖屏与全屏

- 横屏自动使用紧凑工具栏 + 沉浸全屏，按键更大。
- 顶部「**旋转**」键：一键切换横竖屏；**长按**「旋转」恢复跟随系统。
- 竖屏下键盘页 / 触控板页 / 媒体页的分隔条可上下拖动调整比例，**双击分隔条**恢复默认，比例会记住。

## 6. 常见问题（FAQ）

**Q：连上了但打字没反应？**
A：1) 手机蓝牙设置里删除该设备配对，从 App 配对流程重连；2) 确认 App 顶部是「已连接」；3) 检查手机是否装了其它 HID 外设类 App（同一时间只能有一个注册成功），先停用其它 HID App。

**Q：提示「HID 服务未初始化 / 注册被拒绝」？**
A：多为该 ROM 屏蔽了 HID Device profile，或开发者选项里开启了「停用蓝牙 HID 设备配置文件」之类开关。可在开发者选项中查找并关闭；部分机型无法恢复（只能当主机）。

**Q：为什么打不出中文？**
A：蓝牙 HID 只能发送按键码（英文/数字/符号/快捷键），汉字需要被控端自己的拼音输入法。手机打中文、平板直接上屏需要后续的 WiFi 伴侣 App。

**Q：平板上的鼠标指针太小 / 不好看？**
A：光标由平板系统绘制，手机无法修改外观。可到平板「设置 → 辅助功能 / 鼠标」里找**指针大小**调节（iQOO Pad2 可用设置里的搜索框搜「指针」）；部分平板还支持指针颜色/样式。

**Q：手机锁屏/切到后台会断开吗？**
A：App 有前台服务保活，正常使用不会断；如果被系统强制清理（如省电策略极端），重新打开 App 会尝试自动重连。

**Q：能同时连两个设备吗？**
A：HID 注册只保持一个 host 连接，切换设备需要重新配对/连接。

**Q：耗电吗？**
A：主要耗电来自蓝牙与屏幕常亮，正常使用与蓝牙键鼠相近；不用时关闭 App 即可。

## 7. 卸载/重置

- 卸载 App 后，手机蓝牙设置里可能残留配对记录，手动删除即可。
- App 内的比例、布局等偏好保存在本机 SharedPreferences，清除应用数据即恢复默认。
