# 使用说明

> PhoneKB 让 Android 手机变成蓝牙键盘 / 触控板 / 媒体遥控器 / 手柄。被控设备（平板、电脑）零安装、无需 root。

## 1. 环境要求

| 端 | 要求 |
|---|---|
| 手机（控制端） | Android 9（API 28）及以上；系统保留 Bluetooth HID Device profile（部分厂商 ROM 会屏蔽） |
| 被控端 | 支持蓝牙键盘/鼠标的设备：Android 平板/手机、Windows、macOS、Linux、iPadOS |

实测环境：Redmi K40（M2012K11AC，Android 13，HyperOS V816.0.10.0.TKHCNXM）→ iQOO Pad2（iPA2453，Android 14）。

## 2. 安装

1. 下载 `PhoneKB-x.y.z.apk` 并安装；Android 13+ 会询问是否允许安装，需要允许此来源。
2. 首次打开：如提示通知权限，请允许（前台服务保活需要，否则 App 被系统回收后蓝牙会断开）。
3. 蓝牙权限在首次使用时授权。

> v0.36.0 起不再有 WiFi 伴侣 / 二维码 / 语音输入，安装包只有手机端一个 APK。

## 3. 配对（关键步骤）

1. 打开 PhoneKB，App 会自动注册 HID。顶部状态应为「等待平板连接」或「已连接」。
2. 点右上角 **配对**，按弹窗提示操作：手机进入可被搜索状态 5 分钟；如果之前配对过，先在被控端删除旧配对。
3. 在被控设备（平板/电脑）打开蓝牙设置 → 搜索设备 → 找到**手机蓝牙名称**（例如「林」）→ 配对。
4. 回到 App，顶部显示 **已连接 · 设备名** 后即可输入。

> 第一次配对后，如果被控端显示「已连接」但按键无反应，通常在被控端蓝牙设置里「取消配对/忘记设备」，再从 App 配对引导重新走一遍即可（HID 需要正确的配对流程）。

### 各平台注意点

- **Android 平板**：配对成功后系统会把它识别为键盘/鼠标，部分平板需在「设置 → 语言和输入法 → 物理键盘」中确认键盘布局。
- **Windows / macOS / Linux**：直接当作标准蓝牙键鼠即可；macOS 可能要求确认键盘类型。
- **iPadOS**：系统只当标准蓝牙键鼠使用，可用字母/数字/快捷键，中文输入依靠 iPad 自带输入法。

## 4. 各页面说明

### 键盘
- 竖屏：上方触控区（可拖动比例），下方键盘；顶部工具区「切换布局」「触控板」。
- 两套布局：**手机布局**（数字行 + 精简字母 + 符号页）、**电脑布局**（Ctrl+C/V/X/A、Alt+Tab、Tab、反斜杠、Ctrl/Alt/Win、方向键）。
- 符号页：`!@#$` 等符号，左下方 ABC 返回字母页。
- 快捷键行与按键会根据横竖屏自动放大/缩小，横屏按键更大。

### 触控板
- 单指移动 → 鼠标移动；单指点击 → 左键；双指点击 → 右键；三指点击 → 中键。
- 双指上下滑 → 滚轮滚动；右侧 ↑ / ↓ 长按可连续滚动。
- 底部左/中/右三个按键支持按住拖动（拖拽文件、选中等场景）。
- 左侧竖条：**数字**（数字键盘浮层）、**键盘**（键盘浮层）、**菜单**；左上角电源键。
- 浮层数字键盘适合输入锁屏密码等纯数字场景。
- **灵敏度**：触控卡片左上角「灵敏度 1.0x」胶囊 → 指针速度 0.4×–2.5×（含慢/标准/快预设）、加速度开关、滚轮 1–6 行；对触控板页 / 单手遥控台 / 键盘页触控板浮层 / 手柄页触控区同时生效，改完立即生效并记住。
- **延迟相关设置**（帮助 → 更多设置）：
  - **指针点击方式**：抬手点击（默认，滚动/拖拽不会误点）/ 按下即点（最快，但拖动开头可能多出一次点击）
  - **长按拖拽阈值**：250 / 350（默认）/ 450 ms
  - **极速模式**：默认开；移动过程中不重绘提示层、只发按下/松开震动，最跟手
  - **指针延迟测量**：读最近 128 次移动的 p50/p95（age = 手指动作 → 报告发出，cost = 报告自身发送耗时）

### 媒体
- 顶部整行「触控板」按钮：一键弹出触控板浮层（不用切换页面）。
- **媒体卡**：**⏮ 上一段 / ⏯ 播放暂停 / ⏭ 下一段**，右侧每个媒体键都做得很大，方便拇指。
- **−10s / ＋10s 宽键**：点一次进/退 10 秒，**按住连发**（抖音、B 站这类只认进度拖动的播放器靠它）。
  - 播放器不认时，「帮助 → 更多设置 → 媒体页 ±10s 键发什么」改成 **← / → 方向键**
- **功能键卡**（两排 5 个圆键）：音量 + / 音量 − / 静音 / **截屏** / **多任务**；亮度 − / 亮度 + / 返回 / 主页 / 菜单。
  - **截屏** = PrintScreen（KEY_SYSRQ），**多任务** = Alt+Tab；能否生效最终取决于被控端系统和具体 App，个别 App 可能拦截。
  - **亮度 −/＋**：多数设备用蓝牙键码直接生效；iQOO / vivo 等会忽略该 usage 的平板没有效果（App 侧无法绕过）。
- 横屏时媒体卡占 60%、功能卡占 40%，左右并排撑满整屏。
- 功能区高度可拖动调节，留给拇指更舒服的位置。

### 手柄
- **三种布局**（手柄设置 → 布局，切换立即生效并记住，横竖屏各存一套）：
  - **浮键**：左下移动盘、右下 X/Y/A/B、两侧肩键、顶部 SELECT/START，中间留空不挡画面
  - **皮肤**：整块 Xbox 式机身（深紫灰面 + 白色圆环），含 LB/LT/RB/RT 与 L/R 双摇杆
  - **自定义**：任何按键都能拖位置
- **移动盘**：左上「移动盘」→ 手柄设置，可切「按键（十字键）」/「圆盘」（按住滑动选 8 方向、扇区高亮、松手回中）/「摇杆」（真模拟摇杆，摇杆头跟手，输出 X/Y 轴，松手回中；不需要重新配对）
- **摇杆兼容**：同弹窗里的「摇杆同时发方向键」打开后，推杆会同时发 8 方向 hat，只认方向键的老模拟器/主机也能用
- **大小**：移动盘与按键各一个 60%–200% 无级滑块（下方显示「本屏实际 N%」），立即生效并记住
- **摇杆**：皮肤布局按住 L/R 摇杆拖动输出四轴（-127..127），松手回中（首次使用需重新配对一次）
- **触控板**：顶部「触控」小键切 关 / 中间面板 / 整片空白；手势同触控板页，可选「只移动」；右上角「触控板」小键打开可拖动位置的浮层（带 返回/主页/后台，右侧 ↑ ↓ 分别是上滚/下滚，按住连发，按下的半边会高亮）
- **编辑布局**：设置里点「编辑布局」或长按空白约 3 秒，蓝色虚线框拖动，松手即存；顶部「重置 / 完成」；离开页面自动退出
- **排错**：设置里「方向键方向 · 修正一格」可临时纠正旧配对导致的整体偏一格；震动反馈可关

### 双手
- 触控区 + 按键板（音量/媒体/导航/数字+键盘）分工，适合横屏双手握持。
- 顶部「**互换**」键：横屏左右对调 / 竖屏上下对调，状态会记住。

### 单手
- **遥控台**：右侧面板 = 触控区 + 返回/确定/键盘 + 媒体 + 音量，左侧留空方便握持。
- **拇指键盘**：键盘贴着屏幕右侧（可切左手），左侧为「切到遥控台」「切换左右手」。
- 单手模式解决「一只手够不到」的问题，不改变输入字符集。

## 5. 横竖屏与全屏

- 横屏自动使用紧凑工具栏 + 沉浸全屏，按键更大。
- 顶部「**旋转**」键：一键切换横竖屏；**长按**「旋转」恢复跟随系统。
- 竖屏下键盘页 / 触控板页 / 媒体页的分隔条可上下拖动调整比例，**双击分隔条**恢复默认，比例会记住。

## 6. 界面大小与窄屏适配

- **自动适配**：界面以 393dp 宽度为基准，按手机实际屏幕宽度和系统字体大小自动缩放，小屏手机、系统大字体、平板分屏都不会裁切。
- **「更多」菜单**：顶部一栏放不下时（窄屏 / 大字体 / 横屏），右侧会出现「**更多**」按钮，「旋转」「帮助」（双手页还有「互换」）会收进菜单里，点「更多」即可使用。
- **手动调节**：帮助 → **界面大小** → 选择「自动适配（推荐）/ 小（界面更紧凑）/ 标准 / 大（界面更宽松）」，立即生效并记住。
- 想验证窄屏效果（开发者/测试用）：见 [调试参数](调试参数.md) 里的 `simw` / `simfont`。

## 7. 常见问题（FAQ）

**Q：连上了但打字没反应？**
A：1) 被控端蓝牙设置里删除该设备配对，从 App 配对流程重连；2) 确认 App 顶部是「已连接」；3) 检查手机是否装了其它 HID 外设类 App（同一时间只能有一个注册成功），先停用其它 HID App。

**Q：提示「HID 服务未初始化 / 注册被拒绝」？**
A：多为该 ROM 屏蔽了 HID Device profile，或开发者选项里开启了「停用蓝牙 HID 设备配置文件」之类开关。可在开发者选项中查找并关闭；部分机型无法恢复（只能当主机）。

**Q：为什么打不出中文？**
A：蓝牙 HID 只能发送按键码（英文/数字/符号/快捷键），汉字需要被控端自己的输入法。用平板/电脑自带的拼音输入法打中文即可，手机端专注当键盘、触控板和手柄。

**Q：App 被系统清理后平板连不上了？**
A：App 被强制停止等于注销了 HID 外设，平板不会自动把「输入设备」连回来。到平板蓝牙设置里点一下该设备重新连接，或者两端取消配对后重新配对一次。

**Q：平板上的鼠标指针太小 / 不好看？**
A：光标由平板系统绘制，手机无法修改外观。可到平板「设置 → 辅助功能 / 鼠标」里找**指针大小**调节（iQOO Pad2 可用设置里的搜索框搜「指针」）；部分平板还支持指针颜色/样式。

**Q：手机锁屏/切到后台会断开吗？**
A：App 有前台服务保活，正常使用不会断；如果被系统强制清理（如省电策略极端），重新打开 App 会尝试自动重连。

**Q：能同时连两个设备吗？**
A：HID 注册只保持一个 host 连接，切换设备需要重新配对/连接。

**Q：耗电吗？**
A：主要耗电来自蓝牙与屏幕常亮，正常使用与蓝牙键鼠相近；不用时关闭 App 即可。

## 8. 卸载/重置

- 卸载 App 后，手机蓝牙设置里可能残留配对记录，手动删除即可。
- App 内的比例、布局等偏好保存在本机 SharedPreferences，清除应用数据即恢复默认。
