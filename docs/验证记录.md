## 2. 路线验证（现成 App：Bluetooth Remote v0.0.7）

- 从 GitHub Releases 下载 APK（jqssun/android-bt-remote，GPLv3）装到 Redmi K40，与 iQOO Pad2 配对成功
- 平板文本框输入字母/数字/符号、Enter/退格/方向键：全部有效；触控板、媒体键：有效
- 中文输入：无法上屏（HID 只发键码，协议限制）
- 结论：手机作为蓝牙 HID 键盘控制 Android 平板的路线在用户设备上**成立**

## 4. 开发/联调注意事项

- MIUI/HyperOS 可能阻止 `adb install`（`INSTALL_FAILED_USER_RESTRICTED`）：从文件管理器手动安装；已装应用的覆盖升级通常不受限。
- `adb input tap` 在 MIUI 上被拒（InputManagerService SecurityException），UI 验证靠 `am start` + 调试 extra + 截图；屏幕休眠时 `screencap` 只能拍到 15580 字节全黑 PNG，需要用户手动点亮（`input keyevent` 同样缺 INJECT_EVENTS 权限）。
- 横屏截图时用 `--ei orient 2` 启动会触发 Activity 重建，延迟执行的回调（如 `--ei gpedit`、`--ei gpdialog`）会丢；先启动转屏、再发一次只带该参数的 intent。
- 截图：`adb shell screencap -p /sdcard/x.png` + `adb pull`（直接 exec-out 在 PowerShell 里会损坏）。
- HID 日志：`adb logcat -d -s PhoneKB-HID:I AndroidRuntime:E`。
- 频繁 `am force-stop com.phonekb` 会让平板丢掉「输入设备」profile（logcat 出现 `HidDeviceService: Binder died, need to unregister app`），之后手机侧一直是 `state=2 等待平板连接` / `send skipped ... host=false`，必须在平板侧重连或重新配对。
