## 2. 路线验证（现成 App：Bluetooth Remote v0.0.7）

- 从 GitHub Releases 下载 APK（jqssun/android-bt-remote，GPLv3）安装到 Redmi K40；
- 手机蓝牙与 iQOO Pad2 配对成功，App 显示已连接；
- 平板文本框中输入字母/数字/符号、Enter/退格/方向键：**全部有效**；
- 触控板（单指移动、点击、双指滚动）：有效；媒体键：有效；
- 中文输入：**无法上屏**（HID 只发键码，属协议限制）；
- 结论：手机作为蓝牙 HID 键盘控制 Android 平板的路线在用户设备上**成立**。

## 5. 已知问题与修复

1. **MIUI/HyperOS 阻止 adb 安装**：`INSTALL_FAILED_USER_RESTRICTED`（需 SIM 卡才能开「USB 安装」）。解决：手动从文件管理器安装 APK；后期该限制消失，`adb install -r` 恢复正常。
2. **HID 冷启动误报注册失败**：MIUI 首次 `registerApp` 返回 false，约 9ms 后回调 registered=true。已改为延迟 1.5s 判定 + 代数计数，避免闪现「注册被拒绝」。
3. **沉浸全屏崩溃**：`buildUi()` 期间调用 `getWindow().getDecorView().getWindowInsetsController()` 时 DecorView 未 attach 导致 NPE。已改为 post 到 contentFrame 且先检查 `getWindowToken()`。
4. **aapt2 版本号被 manifest 覆盖**：`aapt2 link --version-code/--version-name` 需同时加 `--replace-version` 才生效，已在 tools/build.ps1 修正。
5. **双手模式互换不生效**：布局矩形只在 onSizeChanged 计算，点击互换只改标志。已抽出 relayout() 并在 setSwapped() 中调用（v0.12.1）。
6. **单手拇指键盘按钮文字换行被裁切**：改为 setSingleLine(true) + 固定宽度。

6. **扫码配对方向调整**：初版是手机显示二维码、平板扫（v0.14.0）；实际使用中平板扫手机屏幕不方便，改为**平板显示二维码、手机相机扫码**（v0.15.0），配对成功后平板主动回连手机。
7. **MIUI 禁止 adb 安装新包**：adb install build/PhoneKB-Companion.apk 返回 INSTALL_FAILED_USER_RESTRICTED（新包安装受「USB 安装」开关限制），但已安装包的覆盖升级正常。结论：伴侣 App 只能由用户手动安装到平板，测试靠手机端日志回显。
8. **伴侣页无法被 adb 直接启动**：CompanionActivity 为 exported=false，am start 会抛 SecurityException；改为由 MainActivity 接收调试 extra 并转发（--ei companion 1）。
9. **adb 传 JSON 参数被 shell 破坏**：am start --es pairjson '{...}' 经过 PowerShell → adb → 设备 sh 后引号丢失，extra 变成 URL；调试改用非 JSON 的 pairhost/pairport/pairtoken 三个参数。

## 6. 未验证 / 待验证

- iOS / iPadOS 未实测（HID 键鼠理论上可用，仅支持字母数字，中文需系统输入法）；
- 部分厂商 ROM 屏蔽 HID Device profile 的机型未覆盖；
- 手柄在具体游戏中的映射（Android 游戏对 HID 手柄支持差异较大）；
- 多设备切换、长时间连接稳定性（仅日常短时使用验证）；
- WiFi 伴侣在弱网/多网卡环境下的重连与 IP 变化（当前靠刷新二维码 / 手动改 IP）；
- 平板重启后无障碍自动关闭的重开体验（Android 限制，只能引导用户）。
