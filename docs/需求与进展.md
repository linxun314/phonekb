## 四、限制与结论

1. **中文输入**：HID 只发键码，无法直接上屏汉字（协议层限制）；已用 WiFi 伴侣解决（平板装伴侣 App + 无障碍），但依赖同一局域网。
2. **光标外观**：由被控端系统绘制，手机端无法修改，只能引导用户调整系统设置。
3. **ROM 兼容**：Android 9+ 的 HID Device profile 依赖厂商 ROM；实测 Redmi K40 HyperOS 正常。
4. 同一时间只能有一个 App 注册 HID，冲突时需停用其它 HID 应用。
5. 单个手机 HID 只维持一个 host 连接。
