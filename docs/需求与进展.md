## 四、限制与结论

1. **中文输入**：HID 只发键码，无法直接上屏汉字；需要被控端输入法或 WiFi 伴侣 App。这是协议层限制，不是实现缺陷。
2. **光标外观**：由被控端系统绘制，手机端无法修改，只能引导用户调整系统设置。
3. **ROM 兼容**：Android 9+ 的 HID Device profile 依赖厂商 ROM；实测 Redmi K40 HyperOS 正常。
4. 同一时间只能有一个 App 注册 HID，冲突时需停用其它 HID 应用。
5. 单个手机 HID 只维持一个 host 连接。

## 五、验证结论

现成开源 App（Bluetooth Remote v0.0.7）在用户设备上验证：键盘、触控板、媒体键全部有效（中文不能上屏），证明「手机当平板键盘」路线可行，随后自研 PhoneKB 并达到同等能力，界面按用户反馈多次迭代。详细记录见 [验证记录.md](验证记录.md)。
