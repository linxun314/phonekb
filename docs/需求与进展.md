# 需求与进展（当前版本 v0.37.7）

本文件只记录**当前版本**的需求结论、能力清单与待办，不保留历史版本记录。

## 一、最初的需求确认

| # | 问题 | 结论 |
|---|---|---|
| Q1 | 被控平板系统 | **Android 平板**（实测 iQOO Pad2，Android 14） |
| Q2 | 控制端手机 | **Android 9+ 手机**（实测 Redmi K40，Android 13） |
| Q3 | 路线 | 先用现成开源 App 验证，再自研 → 验证成功后自研 |
| Q4 | 需要的能力 | 键盘+快捷键、触控板/鼠标、媒体键、手柄；剪贴板 / 语音输入曾用 WiFi 伴侣实现，0.36.0 按用户反馈整块移除（扫码配对 + 平板常开无障碍太麻烦，且识别文字会混入搜索框） |
| Q5 | 连接方式 | 蓝牙 / WiFi / USB；**现在只保留蓝牙 HID**，WiFi 伴侣已移除，USB 未做 |
| Q6 | 平板权限容忍度 | 可装 App、开开发者选项，**不 root** |
| Q7 | 中文输入 | 以英文/数字/快捷键为主，中文偶尔用 → 用平板自己的输入法（HID 协议层只能发键码） |
| Q8 | 项目性质 | **开源项目** |
| Q9 | 技术参与度 | 用户不写代码，全部由 AI 实现 |
| Q10 | 节奏 | 尽快能用（当天跑通 MVP，后续按反馈迭代） |

## 二、当前版本已实现

- **主动断开（0.37.7）**：设备列表里当前连着的那行多一个红色「断开」，点了就断掉并且**暂停一切自动重连**（自动重连 / 冷启动回连 / 抢连守护），点「切换」或重启 App 后恢复
- **顶栏重排（0.37.6）**：「设备」变成带手机图标的蓝描边重点按钮；「平板 / 电脑」折叠成一个显示当前模式的按钮（点开是两项菜单）；「旋转」移到页签行常驻；删掉「单手」页签（旧配置自动清理）；设备列表类型角标换成手机 / 显示器 / 电视线稿图标，并修掉设备名被裁一个字的 bug
- **设备切换（0.37.5）**：顶栏电源键右边「设备」面板列出已保存的主机（类型图标 + 名称 + 类型·上次连接时间），点「切换」= 松键 → 断开当前 → 连目标（1–2 秒），已配对设备无需重新配对；「设备抢连守护」默认开，非首选设备抢连时 2 秒内切回。列表只保留电脑 / 平板手机 / 曾连过的设备，过滤耳机手表。
- **电脑模式（0.37.0）**：顶栏「平板 / 电脑」切换被控设备，走同一条蓝牙 HID（Windows 10 / 11 自带 HID 键鼠驱动，电脑端零安装）。电脑模式下键盘快捷键条 = Ctrl+C / Ctrl+V / Win / Win+D / Alt+Tab / 截屏（Win+Shift+S）/ 锁屏（Win+L）；媒体页常用键 = 音量± / 静音 / 截屏 / 任务视图（Win+Tab）｜ 锁屏 / 上一首 / 播放 / 下一首 / 菜单（Shift+F10）。配对弹窗、帮助文案、状态栏、footer 随模式变化，选择持久化在 prefs `device_mode`
- **指针上报节奏（0.37.4）**：触控板卡顿的根因是「两帧间隔 ≥2 ms 就发一份」→ 快划时四五百份/秒，而蓝牙 HID 通道约 90 份/秒，多余的堆在栈里排队；改为按节奏合并发送（默认 9 ms ≈ 111 份/秒，leading edge 立刻发、dx 累加不丢步），更多设置可选 2 / 6 / 9 / 12 ms，延迟弹窗显示实际「节奏 N 份/秒」
- **竖屏拉伸条（0.37.0）**：键盘页在快捷键条与键盘之间拖动改键盘高度（30%–62%，吸附 48 / 58 / 62，双击恢复 58/42）；触控板页 / 媒体页拖动顶部分隔条改功能区高度（默认 80% / 78%）

### 连接与基础
- 蓝牙 HID 复合设备：键盘 / 鼠标 / Consumer / 手柄 4 个 report（手柄含 hat + 16 按键 + 4 轴）
- 配对引导、状态显示、帮助弹窗、前台服务保活、HID 断连自动重注册、注册失败重试
- 单一通道：纯蓝牙 HID，被控端零安装、免 root、免配置（WiFi 伴侣 / 二维码 / 语音 / 无障碍注入已全部删除，App 零第三方依赖）

### 键盘
- 手机布局 / 电脑布局 / 符号页，布局切换记忆
- 快捷键芯片：Ctrl+C/V/X/A、Alt+Tab；电脑布局含 Tab、反斜杠、Ctrl/Alt/Win、方向键
- 顶部工具栏：切换布局 + 触控板浮层
- 竖屏触控区 / 键盘比例可拖动（30%–62%），双击复位，记忆

### 触控板
- 单指移动、点击左键、双指滚动、双指点击右键、三指点击中键、底部左右中拖拽键、右侧滚动列
- 左侧竖条：数字键盘浮层 / 键盘浮层 / 菜单键
- **指针灵敏度**：0.4×–2.5×（预设 0.6 / 1.0 / 1.6）、加速度开/关、滚轮 1–6 行；对触控板页 / 键盘页浮层 / 手柄页触控区统一生效
- 竖屏功能区 / 留空区比例可拖动（45%–100%），双击复位
- **延迟优化**：一帧历史采样全累加、合并窗口 2 ms、极速模式（移动中不重绘/不震动）、点击方式（抬手点击 / 按下即点）、长按拖拽阈值 250/350/450 ms、指针延迟 p50/p95 测量

### 媒体
- 媒体卡三键：上一段 ⏮ / 播放暂停 ⏯ / 下一段 ⏭（按住 ⏮、⏭ 连发）
- 两颗宽键 −10s / ＋10s：只发 ← / → 方向键，点一次退 / 进 10 秒、按住连续快退 / 快进（0.36.2 起不再有「上一段 / 下一段」档位）
- 功能键卡 2×5：音量 + / 音量 − / 静音 / 截屏 / 多任务；亮度 − / 亮度 + / 返回 / 主页 / 菜单
- 顶部整行「触控板」按钮弹出浮层
- 亮度：走蓝牙 Consumer 0x006F / 0x0070；iQOO / vivo 等部分平板会完全忽略该 usage（被控端行为，App 无法绕过）
- 竖屏比例可拖动（55%–100%），双击复位

### 手柄
- 三种布局：**浮键** / **皮肤**（Xbox 式机身 + 双摇杆 + LB/LT/RB/RT）/ **自定义**（拖动编辑），横竖屏各存一套
- 移动盘三形态：十字键 / 圆盘（8 方向、扇区高亮、松手回中）/ 模拟摇杆（0.31.0，摇杆头跟手 + 可选同时发方向键）
- 大小：移动盘、按键（ABXY/肩键/菜单键）各 60%–200% 无级滑块，滑块下显示「本屏实际 N%」，立即生效并记忆
- 输入：ABXY、L1/R1、LT/RT、SELECT/START、L/R 模拟摇杆（-127..127），多指并发
- 触控板：中间空白可当触控板（关 / 中间 / 全屏），可选「完整」或「只移动」；另有可拖动位置的触控板浮层（带 返回/主页/后台）
- 设置项：震动反馈开/关、方向键方向（正常 / 修正一格）、布局编辑入口
- 编辑模式：长按空白约 3 秒或点「编辑布局」进入，蓝色虚线框，拖动即存，重置 / 完成；离开页面自动退出

- **摇杆防卡死**（0.36.2）：移动事件按手指分流，触控板只处理自己的手指，其余手指继续喂摇杆（两者可同时用）；极速模式下摇杆位移也重绘（只重绘摇杆矩形）；追踪手指失效立刻归零

### 双手
- 触控区 + 按键板（音量/媒体/导航/数字+键盘），「互换」即时对调并记忆（0.37.6 起「互换」在页签行右端）
- 单手页签在 0.37.6 移除（早期遥控台形态，实际不用）

### 界面
- 横屏紧凑工具栏 + 沉浸全屏；「旋转」键强制横竖屏（长按恢复跟随系统），0.37.6 起一直露在页签行不再折叠进「更多」
- 自适应：393dp 基准 + 系统字体缩放（0.78–1.15），顶栏放不下折叠到「更多」；帮助 →「界面大小」四档
- 比例拖动、双击复位、全部记忆；横竖屏各一套布局参数
- 平板指针大小指引（系统设置里调）

## 四、限制与结论

1. **中文输入**：HID 只发键码，无法直接上屏汉字（协议层限制）；用平板自己的输入法输入中文，手机端专注当键盘/触控板/手柄。
2. **光标外观**：由被控端系统绘制，手机端无法修改，只能引导用户调整系统设置。
3. **ROM 兼容**：Android 9+ 的 HID Device profile 依赖厂商 ROM；实测 Redmi K40 HyperOS 正常。
4. 同一时间只能有一个 App 注册 HID，冲突时需停用其它 HID 应用。
5. 单个手机 HID 只维持一个 host 连接。
6. App 被系统杀掉等于注销 HID 外设，平板不会自动重连「输入设备」，需在平板蓝牙里点一下该设备。

## 五、路线验证结论

用现成开源 App（Bluetooth Remote v0.0.7）在用户设备上验证：键盘、触控板、媒体键全部有效（中文不能上屏），证明「手机当平板键盘」路线可行；随后自研 PhoneKB 并达到同等能力，界面按用户反馈持续迭代。详细记录见 [验证记录.md](验证记录.md)。
